# Connexion via Steam uniquement

Les utilisateurs s'identifient exclusivement avec « Se connecter via Steam » (OpenID de Steam) : pas d'e-mail ni de mot de passe. Tous les utilisateurs visés ont un compte Steam, cela évite de stocker et sécuriser des mots de passe, et cela fournit directement le SteamID nécessaire pour importer la liste de souhaits et proposer le pays.

## Consequences

- Sans compte Steam, impossible d'utiliser l'appli ; c'est assumé.
- Comme il n'y a pas d'e-mail, aucun canal d'alerte par e-mail n'est possible sans ajouter une collecte d'adresse.

# Alerte de démo et badge Démo disponible

Status: ready-for-agent
Blocked by: 08

## Quoi

Détecter l'apparition d'une démo sur un jeu suivi. Les DLC ne sont pas concernés.

## Critères d'acceptation

- [ ] Une alerte quand une démo apparaît sur un jeu déjà suivi.
- [ ] Un jeu suivi qui avait déjà une démo affiche le badge « Démo disponible », sans alerte.
- [ ] Une démo retirée puis republiée déclenche une nouvelle alerte.
- [ ] L'alerte contient un lien qui ouvre la démo dans Steam.
